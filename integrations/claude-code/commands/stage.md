Record your provisional thesis so the envelope permits writes. Run this exact command:

`node ${CLAUDE_PLUGIN_ROOT}/scripts/stage-write.js "<one-paragraph thesis: answer-first conclusion, key hypotheses, and the write you intend>"`

After staging, continue only with reads and writes that test or fulfill the thesis. If a write is refused, the envelope will replay this thesis — resume from it; do not restart research.
